# Methodology

The Methodology area of [API Evangelist](https://apievangelist.com), published at
**https://methodology.apievangelist.com**.

It covers the methodologies that shape how software and APIs are planned, built and run: Scrum,
Extreme Programming, Lean and Lean Six Sigma, the software development lifecycle, project
management methods, and the working artifacts they produce (product backlogs, user stories, RACI
matrices, Gantt charts). These are practices, not products, so each is a term in this area rather
than a provider in the catalog. Every term also has a topic page on [APIs.io](https://apis.io/topics/).

Created 2026-10-28 (api-evangelist/roadmap#881). The site is Jekyll on GitHub Pages; its content
comes from `_data/area.yml` and `_data/network.yml`.
